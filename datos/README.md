# Datos

Esta carpeta contiene datasets pequeños usados por los ejemplos del libro.

## Archivos

- `mpg.csv`: dataset `mpg` usado en los ejemplos de árboles de regresión. Se incluye localmente para evitar errores de certificados SSL o dependencias de red al ejecutar los notebooks.
- `credit-g.csv`: dataset `credit-g` de OpenML, usado en ejemplos de clasificación y riesgo crediticio. Se incluye localmente para evitar descargas durante la ejecución de los notebooks.
